# TUICodingAgent 第 4 章需求规格

## 目标

将第 3 章固定两阶段工具闭环升级为自主 ReAct Agent Loop。Agent 持续执行“模型流式响应 → 工具调用 → 结果回灌”，直到自然完成或触发明确停止条件。

## 功能范围

1. 最多 12 次模型迭代；自然文本回复立即完成。
2. 连续 3 轮仅请求未知工具时停止。
3. Provider 错误、用户取消、迭代上限均合法收尾，下一轮仍可继续。
4. 事件流包含文本、迭代、工具开始/结束、Token 用量、完成、错误、取消与停止提示。
5. `read_file`、`glob`、`grep` 为只读工具；连续只读调用并发，写、改、Bash 单独串行；结果保持模型原顺序。
6. OpenAI 与 Anthropic 均解析流式用量。
7. 流式态 Esc/Ctrl+C 取消本轮，空闲态 Ctrl+C 退出。
8. `/plan` 进入仅只读工具的计划模式；`/do` 回到执行模式并立即执行上文计划。

## 非目标

本章不实现权限确认、沙箱、上下文压缩、计划审批/落盘、子 Agent、Token 预算停止或配置化迭代上限。

## 常量

- Agent 最大迭代：12
- 连续未知工具轮次阈值：3
- 单工具超时：沿用 30 秒

## 自动审批记录

用户已授权所有审批位置自动批准，本规格直接批准进入设计与实现。
